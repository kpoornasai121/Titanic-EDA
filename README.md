## What’s This Project About?

This project analyzes the Titanic dataset to understand survival patterns among passengers. Using Python and libraries like Pandas, Seaborn, and Matplotlib, I explore how factors like fare prices relate to survival rates. The goal is to reveal insights through data exploration and visualizations, like survival rates by fare groups, to better understand what influenced outcomes on the Titanic.

## Cool Features

- **Data Exploration**: Dig into passenger details like age, class, fare, and survival status.
- **Visual Insights**: Bar plots (like survival by fare group) make patterns easy to spot.
- **Clean Analysis**: Uses Pandas for efficient data handling and Seaborn for beautiful visuals.
- **Beginner-Friendly**: Perfect for anyone learning data analysis with Python.

## What Data Powers It?

The project uses the Titanic dataset (`train.csv`), likely sourced from [Kaggle](https://www.kaggle.com/c/titanic/data). It includes:
- **Columns**: PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked.
- **Size**: 891 entries, with some missing values (e.g., Age, Cabin).

Key fields:
- **Survived**: 0 (did not survive) or 1 (survived).
- **Fare**: Ticket price, used to group passengers for analysis.
- **Pclass**: Passenger class (1st, 2nd, or 3rd).

## Getting Started

Want to run this analysis yourself? Here’s how to set it up:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/kpoornasai121/Titanic-EDA.git
   cd titanic-survival-analysis
   ```

2. **Get the Dataset**:
- Download train.csv from Kaggle’s Titanic competition.
- Place it in a data folder in the project directory.

3. **Launch Jupyter Notebook**:
   ```bash
   jupyter notebook
   ```
Open titanic.ipynb in your browser to explore the analysis.
